# 仿鱼泡网小程序源码招工招聘找活名片信息分类同城工地招工网站源码tp框架

源码地址：ym7k.com/19259/

这套是基于 ThinkPHP 开发、仿鱼泡网模式的蓝领工地劳务招工系统，支持 H5 + 微信小程序双端，专门面向建筑工友、包工头、班组，主打工地招工、工人找活，是垂直于建筑劳务行业的同城招工平台。

### 两大角色：招工方 & 工友

✅ **包工头 / 招工方（找工人）**

- 快速发布招工信息，标注工种、工地地点、工期、薪资要求
- 浏览工友名片、查看工人项目经验、技能、工龄、意向工作地
- 查看谁看过我的招工信息，管理自己发布的招工帖子
- 置顶、刷新帖子，提高曝光，快速招到班组、技工、普工

✅ **工人 / 工友（找工作）**

- 制作专属「找活名片」：个人简介、工龄、工种、期望工作地点
- 上传项目经历，附带工地实拍图，展示过往施工案例、职业技能
- 浏览附近招工、最新工地活源，收藏、点赞、分享招工信息
- 管理自己发布的找活信息，查看浏览记录，对接包工头

### 核心功能清单

- 🏠 首页：工种分类、最新招工信息流、附近活源、邀请工友入口
- 🪪 找活名片：工友个人主页，项目经验图文展示、技能标签，支持点赞、分享、收藏
- 👷 双入口：【找工作】工人找活｜【找工人】包工头招工
- 🧾 会员中心：积分体系、积分充值、积分明细；实名认证、实名查询
- 📩 消息模块：站内消息通知，招工对接消息
- 📈 流量运营：帖子置顶、刷新推广（核心变现）
- 👥 邀请工友：拉新推广机制，适合劳务社群裂变
- 🧑‍💻 后台管理：招工信息审核、用户管理、积分配置、广告管理、分类管理

### 系统亮点

- 🟦 ThinkPHP 框架，代码易二次开发，私有化部署
- 🟦 垂直工地蓝领劳务，区别于普通白领招聘，贴合建筑行业需求
- 🟦 特色找活名片，项目案例图文展示，包工头直观筛选工人
- 🟦 同城附近定位，优先展示就近工地招工信息
- 🟦 积分付费置顶、刷新，成熟的劳务平台变现模式
- 🟦 实名认证，降低招工、找活的信任风险
- 🟦 小程序 + H5，工友不用下载 APP，微信直接打开使用

### 盈利方式

帖子置顶费、刷新曝光、会员套餐、积分充值、广告位、拉新奖励、招工信息发布费

### 适用场景

建筑工地招工平台、工友找活平台、本地劳务班组对接、蓝领招工、建材工地垂直平台、县城劳务市场，对标鱼泡网、吉工家模式。
